# ATCS-215 Spec

## Feature Specification

- 로그인 화면에서 이메일 허용 안내 문구를 제거한다.
- 로그인 1단계 버튼의 화살표 아이콘을 제거하고 버튼 문구를 정리한다.
- 로그인 2단계 성공 박스 문구를 짧게 정리하고 로그인 버튼 앞 체크 아이콘을 제거한다.
- 헤더에서 갱신 시간을 제거한다.
- 자동 실행 상태 pill을 상태 동기화 버튼 왼쪽으로 이동한다.
- 헤더 버튼 문구를 `상태 동기화`로 변경한다.
- 첫 번째 요약 카드 제목을 `최근 동기화 시간`으로 변경한다.
- 오늘 상태 변경 카드 하단 문구를 `품절 전환`, `판매 전환` 기준으로 변경한다.
- 전체 상품 목록 테이블에서 `동기화 일자` 컬럼을 제거한다.
- 계정 드롭다운에서 `배치 간격 설정`을 `자동 실행 설정`, `자동 실행 간격`을 `실행 시간`으로 변경한다.
- 상품 추가 모달에서 범용 선택 상태가 더 잘 보이도록 스타일을 조정한다.
- 상품 추가/수정 모달의 구분 버튼 하단 `재고 N개 이하 → 품절` 보조 문구를 제거한다.
- 엑셀 업로드 관련 문구를 `엑셀 업로드`, `업로드` 기준으로 정리한다.

## Validation Rules

- 기존 로그인, 배치 실행, 알림 설정, 상품 추가, 엑셀 업로드 동작은 유지되어야 한다.
- 상품 목록 테이블은 컬럼 제거 후에도 기존 데이터 행 수와 액션 버튼 정렬이 유지되어야 한다.
- 상품 목록 테이블은 동기화 일자 컬럼 제거 후 빈 폭이 남지 않도록 남은 컬럼 비율이 다시 맞춰져야 한다.

## Edge Cases

- 자동 실행 스케줄이 없을 때도 헤더 버튼/레이아웃이 깨지지 않아야 한다.
- 상품 목록 로딩/에러/빈 상태의 `colSpan` 값이 새 컬럼 수와 일치해야 한다.
- 모바일에서도 헤더 우측 요소가 과도하게 겹치지 않아야 한다.

## Acceptance Criteria Mapping

- 로그인 문구와 아이콘 정리: 로그인 화면 렌더링 확인
- 헤더 문구/배치 변경: 대시보드 헤더 렌더링 확인
- 최근 동기화 시간 카드 제목 변경: 첫 번째 요약 카드 라벨 확인
- 상태 변경 용어 변경: 요약 카드 문구 확인
- 동기화 일자 컬럼 제거: 상품 목록 헤더와 행 구조 확인
- 자동 실행 설정 문구 변경: 계정 드롭다운 렌더링 확인
- 상품 추가/수정 구분 보조 문구 제거: 두 모달에서 하단 텍스트 미노출 확인
- 업로드 문구 변경: 대시보드 버튼과 업로드 모달 확인
- 범용 선택 강조: 상품 추가 모달 선택 상태 확인
