# ATCS-216 Spec

## Feature Specification

- 전체 상품 목록 카드 헤더에 `엑셀 다운로드` 버튼을 추가한다.
- 버튼은 `엑셀 업로드` 버튼의 왼쪽에 배치한다.
- 다운로드는 화면에 보이는 페이지가 아닌 전체 상품 데이터(`allItems`)를 기준으로 수행한다.
- 파일 형식은 `.xlsx`이고, 시트명과 컬럼 헤더 및 컬럼 폭을 포함한 기본 포맷을 적용한다.
- 상품 데이터가 없을 때는 다운로드를 수행하지 않고 사용자에게 오류 토스트를 보여준다.

## API Changes

- 없음

## Database Changes

- 없음

## Domain Model Changes

- 없음

## Validation Rules

- 다운로드 파일에는 전체 상품 목록에서 운영상 필요한 주요 컬럼만 포함한다.
- 필터, 검색어, 정렬, 페이지네이션 상태와 무관하게 전체 상품 데이터가 내려받아져야 한다.
- 다운로드 기능 추가 후 기존 상품 목록 조회, 업로드, 추가/수정/삭제 동작은 유지되어야 한다.

## Edge Cases

- 상품 데이터가 0건이면 파일을 생성하지 않는다.
- `updatedAt`, `createdAt`, `createdId`, `updatedId`가 비어 있어도 파일 내 값은 `—` 또는 대체 가능한 값으로 정규화한다.
- 고도몰 미연동 상품은 판매 상태를 `확인불가`로 표기한다.

## Exception Scenarios

- 파일 생성 중 예외가 발생하면 사용자에게 실패 토스트를 보여준다.

## Acceptance Criteria Mapping

- 버튼 위치 추가: 전체 상품 목록 카드 헤더에서 `엑셀 다운로드` 버튼 확인
- 전체 데이터 다운로드: 페이지/필터 상태와 무관하게 전체 상품 데이터가 파일에 포함되는지 확인
- 파일 포맷 적용: 시트명, 헤더명, 컬럼 폭이 적용된 `.xlsx` 생성 확인
- 빈 데이터 예외 처리: 데이터가 없을 때 실패 토스트 확인
