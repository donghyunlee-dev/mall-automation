# Iteration 28 계획 — 주문 동기화 에러 메시지 레이아웃 수정

> 작성일: 2026-09-09

## 배경

`OrderSyncControl`의 `.wrap`이 상태/날짜입력/버튼/에러메시지를 전부 한 줄 flex row로 배치하고 있어, 에러 메시지가 뜨면 버튼 오른쪽에 이어붙으면서 컨트롤 전체 폭이 늘어난다. 이 컨트롤은 대시보드 헤더(`justify-content: space-between`)의 우측에 있어서, 폭이 늘어나면 좌측 타이틀 쪽까지 레이아웃이 밀린다.

## 범위

- 상태/날짜입력/버튼을 하나의 행(`.row`)으로 묶고, 에러 메시지는 그 아래(또는 위) 별도 줄에 표시
- 버튼을 포함한 컨트롤 행 자체의 위치/폭은 에러 메시지 유무와 무관하게 고정

## 완료 기준

- [x] `npm run build`/`lint`/`test` 통과
