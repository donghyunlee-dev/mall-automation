### 참고 (mock 서버 한계)

mock `revenue-trend` 엔드포인트는 `bucket` 파라미터를 반영하지 않고 항상 1일 간격으로 더미 데이터를 생성한다. 따라서 "최근 5주 추이"의 x축 라벨이 실제로는 5일 간격으로 보이지만, 막대/포인트 개수(5개)와 레이아웃 확인에는 지장이 없다. 실제 백엔드는 `TrendBucketUnit.WEEK` 처리 시 요일별로 정확한 주 단위 버킷을 반환하므로(Iteration 11에서 이미 구현·테스트 완료) 별도 조치는 불필요.
