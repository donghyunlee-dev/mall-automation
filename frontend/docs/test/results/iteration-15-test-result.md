### 확인 중 발견·수정한 이슈

mock 서버의 `revenue-trend`/`grade-pivot`이 `bucket=QUARTER`를 별도로 처리하지 않아 일(day) 단위로 폴백되면서, "최근 8분기 추이"·"분기별 실적 상세"가 8개의 서로 다른 날짜 대신 8일치 데이터로 잘못 표시됐다. `buildBucketEnds` 헬퍼로 통합해 MONTH/QUARTER를 공통 로직(월 인덱스 기반)으로 처리하도록 수정 — **실제 백엔드(`DashboardPeriodResolver.resolveQuarterly`)에는 이 문제가 없음, mock 서버 전용 버그**.

### 참고

- 백엔드 신규 작업 없이(월간 탭에서 이미 지원되는 API 그대로 재사용) 프론트 구현만으로 완료 — MONTH/QUARTER 버킷은 이미 출고일 기준 자동 처리되므로 `dateBasis` 파라미터가 필요 없었음.
- 4개 탭(일간/주간/월간/분기) 전체 구현 완료.
