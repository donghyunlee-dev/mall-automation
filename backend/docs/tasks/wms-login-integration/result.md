# WMS 로그인 연동 결과

## 제공 범위

- 로그인 화면에서 시작하는 WMS 로그인 연동 가이드를 작성했다
- 로그인 요청, 결과값, 세션 재사용 순서를 정리했다
- 로그인 이외의 WMS 기능 설명을 제거했다
- 비밀번호 SHA-256 해시 처리 규칙을 정리했다

## 변경 내용

- WMS 로그인 연동 안내 문서
- 작업 문서 세트

## 핵심 결정

- 문서는 로그인 화면과 로그인 API 사용법에만 집중했다
- 세션 쿠키는 실행 중 임시 값으로만 사용한다
- 원문 비밀번호를 받은 경우에는 먼저 SHA-256 해시해야 한다
