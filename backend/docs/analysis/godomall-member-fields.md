## 2. 회원 목록 DOM 구조 (member_list.php)

각 회원 행의 `<input type="checkbox" name="chk[]">` 에 핵심 식별자가 담겨 있습니다.

```html
<input type="checkbox" name="chk[]"
  value="{memNo}"               <!-- DB PK. member_modify.php?memNo= 에 사용 -->
  data-memid="{mem_id}"         <!-- 로그인 아이디 -->
  data-memnm="{mem_name}"       <!-- 이름 -->
  data-deposit="{deposit}"
  data-mileage="{mileage}"
  data-couponcount="{count}"
  data-appfl="{app_fl}"
  data-maillingfl="{mailling_fl}"
  data-smsfl="{sms_fl}"
  data-cellphone="{cell_phone}"
  data-email="{email}">
```

### 주요 URL 패턴

| 용도 | URL |
|------|-----|
| 회원 목록 (전체) | `/member/member_list.php?searchFl=y&searchPeriod=-1` |
| B2B 거래처 목록 | `/member/member_list.php?searchFl=y&groupSno=9&searchPeriod=-1` |
| 회원 상세/수정 | `/member/member_modify.php?memNo={memNo}` |
