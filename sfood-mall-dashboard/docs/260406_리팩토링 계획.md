### 2. metric에 전기간 대비 delta 추가 (그로스 인사이트)

숫자가 좋은지 나쁜지 맥락을 파악할 수 없다.

**목표**
```
현재:  일간 총 매출  1,234,000원
개선:  일간 총 매출  1,234,000원   ▲ +12.3%  (전일 대비)
```

**체크리스트**
- [ ] **일간 탭** — `end_date - 1일`의 데이터를 동일 로직으로 집계해 `prev_daily_*` 변수 산출
- [ ] 일간 metric 6개에 `delta=f"{변화율:+.1f}%"` 및 `delta_color` 적용
  - 매출, 주문건수, 주문자수, 평균SKU, 평균수량, AOV
- [ ] **주간 탭** — `end_date - 7일` 기준 직전 7일 데이터 집계해 `prev_weekly_*` 산출
- [ ] 주간 metric 6개에 전주 대비 delta 적용
- [ ] **월간 탭** — `selected_month` 직전 월 데이터 집계해 `prev_monthly_*` 산출
- [ ] 월간 metric 7개에 전월 대비 delta 적용
- [ ] delta 계산 시 분모가 0인 경우(직전 기간 데이터 없음) 예외 처리
- [ ] delta 포맷: 증감률(%) 기본, 매출은 절대 금액 차이도 병기 여부 결정
